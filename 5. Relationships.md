
### Star Schema 101
A star schema has one fact table at the center surrounded by dimension tables. This is the standard structure for Power BI data models.

```
              dim_customers
                    |
dim_products — fact_orders — dim_dates
                    |
              dim_regions
```

**Rules:**
- The fact table holds numbers and foreign keys only
- Dimension tables hold descriptive attributes
- Every foreign key in the fact table links to a primary key in a dimension
- Filters flow from dimension → fact (single direction)
- No repeated attribute columns in the fact table — if it describes something, it belongs in a dimension

### Complicated Relationships

**Inactive relationships**
You can have multiple relationships between two tables but only one can be active at a time. Use USERELATIONSHIP() in DAX to activate an inactive one inside a specific measure.

```dax
Sales by Ship Date =
CALCULATE(
    [Total Revenue],
    USERELATIONSHIP(fact_orders[ship_date], DateTable[Date])
)
```

**Bidirectional filtering**
By default filters flow from dimension to fact only. Setting Both means filters travel in both directions. Use sparingly — it can create ambiguous results and slow performance.

**Role-playing dimensions**
When the same dimension (e.g., DateTable) links to the fact table multiple times (order_date, ship_date, delivery_date), only one relationship is active. The others are inactive dashed lines accessed via USERELATIONSHIP.

## Date Table

### Master Code
Copy and paste this every project. Never rely on Power BI auto date hierarchy.

```dax
DateTable =
CALENDAR(
    DATE(2020, 1, 1),
    DATE(2025, 12, 31)
)
```

Add these calculated columns inside DateTable:

```dax
Year       = YEAR([Date])
MonthNum   = MONTH([Date])
MonthName  = FORMAT([Date], "MMM")
Quarter    = "Q" & ROUNDUP(MONTH([Date]) / 3, 0)
YearMonth  = FORMAT([Date], "YYYY-MM")
WeekNum    = WEEKNUM([Date])
WeekDay    = FORMAT([Date], "ddd")
WeekDayNum = WEEKDAY([Date], 2)
IsWeekend  = IF(WEEKDAY([Date], 2) >= 6, TRUE, FALSE)
FiscalYear = IF(MONTH([Date]) >= 4,
               "FY" & YEAR([Date]),
               "FY" & (YEAR([Date]) - 1))
```

### Mark as Date Table
Mandatory for time intelligence functions to work correctly (DATEADD, DATESYTD, etc.).

**How:**
Click DateTable in the Fields pane → Table Tools → Mark as Date Table → select the [Date] column

Without this step, time intelligence DAX functions return blank or incorrect results even if the table looks correct.

> 📸 Screenshot: Table Tools ribbon → Mark as Date Table dialog


### Sort MonthName by MonthNum
Without this step, months sort alphabetically (Apr, Aug, Dec) instead of chronologically (Jan, Feb, Mar).

**How:**
1. Click the MonthName column in DateTable
2. Column Tools → Sort by Column → MonthNum

> 📸 Screenshot: Chart with alphabetical months → after sort fix showing Jan to Dec

### Discrete vs Continuous Date Axis

| | Discrete (Categorical) | Continuous |
|---|---|---|
| **Appearance** | Even spacing regardless of time gaps | Gaps appear where no data exists |
| **Use when** | Comparing periods as categories | True time series where gaps matter |
| **How to set** | Click axis → type = Categorical | Click axis → type = Continuous |

When your line chart shows uneven spacing or jumps, check the axis type first before investigating your data.
