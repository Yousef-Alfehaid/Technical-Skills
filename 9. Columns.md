### Extract Text or Numbers Only
Use when a column contains mixed content like "Order123" and you need just the number or just the text.

**Extract numbers only:**
```m
= Text.Select([column_name], {"0".."9"})
```

**Extract letters only:**
```m
= Text.Select([column_name], {"a".."z", "A".."Z"})
```

**Extract after a delimiter:**
```m
= Text.AfterDelimiter([column_name], "-")
// "ORD-00123" becomes "00123"
```

### Conditional Column vs Custom Column

| | Conditional Column | Custom Column |
|---|---|---|
| **How** | UI dropdown — no code | Write M code manually |
| **Use when** | Simple if/else rules with fixed values | Complex logic, calculations, referencing functions |
| **Example** | If region = "Riyadh" then "Central" else "Other" | Combining columns, extracting patterns, math |
| **Skill signal** | Basic | Intermediate–Advanced |

**Conditional Column (UI):**
Add Column → Conditional Column → set rules visually

**Custom Column (M code):**
```m
// Simple condition
= if [region] = "Riyadh" then "Central" else "Other"

// Calculation
= [unit_price] * [quantity] * (1 - [discount_pct] / 100)
```

## 7. Handling Nulls [columns]

### Nulls vs Blanks in DAX

| | Null (from source) | BLANK() in DAX |
|---|---|---|
| **Origin** | Missing value in the data | DAX returns this when no rows match |
| **In Power Query** | Visible as null, can be replaced | Does not exist at this stage |
| **In DAX arithmetic** | Can cause errors | Treated as zero in most operations |
| **Fix** | Replace in Power Query before loading | Use COALESCE or IF(ISBLANK()) in DAX |

---

### Replace Nulls in Power Query
**UI:** Right-click column → Replace Values → leave "Value to Find" empty → type replacement value

**In M code:**
```m
= Table.ReplaceValue(Source, null, 0, Replacer.ReplaceValue, {"column_name"})
```

### Handle Blanks in DAX
```dax
// Replace blank with zero
Safe Revenue =
IF(ISBLANK([Total Revenue]), 0, [Total Revenue])

// COALESCE — returns first non-blank value (cleaner)
Safe Revenue =
COALESCE([Total Revenue], 0)

// Always use DIVIDE instead of / operator
// DIVIDE returns blank when denominator is 0 — the / operator returns an error
Safe AOV =
DIVIDE([Total Revenue], [Total Orders])
```
